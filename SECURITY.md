# Security policy

## Reporting an issue in this repository

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository. Please do not open a public issue for security problems.

## Issues in upstream projects

Fixes under `upstream-fixes/` concern third-party projects. Report problems with those projects to their maintainers through each project's own security process.

## Disclosure

Security-relevant findings in third-party software are disclosed to the maintainer first and published here only after a fix is available or the maintainer agrees.
